Cómo conectar pedidos de clientes reales

Ya tienes un backend real conectado. El siguiente paso, que no depende de este archivo, es que un desarrollador conecte cada canal (WhatsApp Business API, formulario web, CRM) al endpoint de abajo usando la clave de tu empresa.

1 · Formato de pedido (contrato de datos)

{ "cliente": "Restaurante El Roble", "telefono": "600111222", "direccion": "Calle Mayor 12, Madrid", "tipo": "Climatización", "prioridad": "urgente", "duracion": 60, "horario": "09:00", "material": "Gas refrigerante", "observaciones": "Avería en sala principal" }
tipo: Climatización · Electricidad · Fontanería · Placas solares · Telecomunicaciones · Reformas · Mantenimiento industrial.
prioridad: urgente · alta · media · baja. duracion en minutos. Se puede enviar un pedido o una lista de pedidos.

2 · Endpoint real de tu backend

POST <URL de tu backend>/v1/pedidos X-API-Key: <clave de tu empresa, abajo> Content-Type: application/json { ... mismo JSON de arriba ... }
Este es el endpoint real y ya activo de tu backend. Cualquier sistema (WhatsApp Business API, un formulario web, email parseado, un CRM) puede llamarlo directamente con la clave de tu empresa — no necesita usuario ni contraseña del panel.
